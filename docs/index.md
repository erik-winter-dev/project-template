# Dokumentation – <PROJEKTNAME>

Diese Dokumentation wächst mit dem Projekt. Nicht benötigte Bereiche werden gelöscht.

## Struktur

| Bereich | Inhalt | Ort |
|---|---|---|
| Architektur | Bausteine, Schnittstellen, Laufzeitsichten (z. B. C4-Diagramme) | `architektur.md` |
| Datenbank | ER-Diagramm, Tabellen, Muster | `datenbank.md` |
| Tests | Teststrategie, Testfälle, Protokolle | `tests.md` |
| Betrieb | Monitoring, Backup, Runbooks | `betrieb.md` |
| Entscheidungen | Architekturentscheidungen mit Begründung | `adr/` |
| Lernen | Lerntagebuch: was gebaut wurde, warum so, was gelernt | `lerntagebuch/` |
| Projektstart | Anleitung, um aus der Vorlage ein neues Projekt zu machen | `projekt-starten.md` |

## Konventionen

- Sprache: Deutsch. Bezeichner im Code und Commit-Meldungen: Englisch.
- Jede Entscheidung mit Begründung als ADR (Vorlage: `adr/0000-template.md`).
- Keine Zugangsdaten, IPs oder Hostnamen in der Doku.
