# Lerntagebuch

Hier steht, was in diesem Projekt gebaut wurde, warum so und was dabei gelernt wurde.
Es gehört zur Lernregel in [`RULES.md`](../../RULES.md), Abschnitt 6: KI-geschriebener Code wird
erst committet, wenn er in eigenen Worten erklärt werden kann.

## Ablauf

1. Pro Feature oder Lerneinheit eine Datei anlegen: `JJJJ-MM-TT-thema.md`.
2. Die Vorlage [`0000-vorlage.md`](0000-vorlage.md) kopieren und ausfüllen.
3. Den Abschnitt „Erklärung in eigenen Worten“ **ohne KI** schreiben. Ist er nicht möglich, ist der Code noch nicht verstanden und wird noch nicht committet.
4. Den Eintrag zusammen mit dem Code committen.
